# AlkkyBypass (ou AlkPass):

negocio de bypass do discord;
faz o compartilhamento de tela e a camera funcionarem denovo usando um proxy SOCKS5.

## compilando (preferência):
baixe o MinGW/GCC com o C++20 e rode `build.bat`.

## usando
baixe um dos releases/compile você mesmo e rode o EXE. quando terminado, o discord vai abrir com a câmera e o compartilhamento de tela liberado. wow!!!!!! (ou é pra isso acontecer, no mínimo)
